# 01. SITEMAP PURPOSE

This document defines the complete information architecture, page structure, navigation and URL system for the Kannan Thangavel personal website.

The website has two primary goals:

1. Present Kannan's professional UX/UI experience clearly for job opportunities.
2. Present Kannan's design and development capabilities for freelance opportunities.

The architecture must also support future development projects without requiring a major redesign.
