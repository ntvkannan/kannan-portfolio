## RESPONSIVE DESIGN SPECIFICATIONS

### Breakpoints

**Desktop:** 1200px+ (primary design reference)
**Tablet:** 768px – 1199px
**Mobile:** 375px – 767px

### Layout Adjustments by Breakpoint

**Desktop (1920px)**
- Hero: Logo composition prominent, ~600px height
- Sections: 2-column layouts where applicable (text + image)
- Images: Large, full-impact presentations
- Spacing: Generous (60px+ gaps)
- Copy: Ideal reading measure (600–700px)

**Tablet (768px)**
- Hero: Stack vertically, logo ~400px
- Sections: Reflow to single column or 2-equal columns
- Images: Medium size, full-width or ~350–400px
- Spacing: Moderate (40–50px gaps)
- Copy: Adapt to narrower measure

**Mobile (375px)**
- Hero: Stack vertically, logo ~250px
- All sections: Single column, full-width
- Images: Responsive scale (max ~350px), full-width with margin
- Spacing: Tighter (20–30px gaps)
- Copy: Full-width, optimized for mobile reading
- No side-by-side layouts that become too small

### Image Scaling Rules

**Large Feature Images** (hero, website, full-width sections)
- Desktop: Full constrained width
- Tablet: Full container width, constrained max-width
- Mobile: Full-width with side margins, readable scale

**Medium Images** (2-column layouts)
- Desktop: ~45% container width
- Tablet: Full-width or reduced column
- Mobile: Full-width, stacked

**Small Images** (logo, badges, grid items)
- Desktop: Fixed or proportional size
- Tablet: Maintain proportion
- Mobile: Scale down proportionally, center if needed

### Rhythm & Spacing

**Desktop:**
- Section top margin: 120px
- Section bottom margin: 120px
- Content padding: 60–80px left/right
- Image gaps: 60px

**Tablet:**
- Section top margin: 80px
- Section bottom margin: 80px
- Content padding: 40–50px left/right
- Image gaps: 40px

**Mobile:**
- Section top margin: 60px
- Section bottom margin: 60px
- Content padding: 20px left/right
- Image gaps: 20–30px
