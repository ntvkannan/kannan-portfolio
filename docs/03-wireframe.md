# 01. PURPOSE

This document defines the structural wireframe for the Kannan Thangavel personal website.

The wireframe should answer:

- What appears on each page?
- In what order?
- What is the visual priority?
- What content belongs in each section?
- Where should the user go next?
- How should desktop and mobile layouts behave?

This document does NOT define final visual styling.

The visual design must follow:

00-design-system.md

The actual content must follow:

01-content.md

The page structure must follow:

02-sitemap.md

---

# 02. WIREFRAME PRINCIPLE

The website should feel:

Professional
